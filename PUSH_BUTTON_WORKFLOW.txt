群底部按钮推送功能工作流程 (Group Bottom Button Push Workflow)
═══════════════════════════════════════════════════════════════

┌─────────────────────────────────────────────────────────────┐
│                     管理员操作流程                            │
│                  (Administrator Workflow)                    │
└─────────────────────────────────────────────────────────────┘

Step 1: 登录管理后台 (Login to Admin Panel)
   │
   ↓
┌────────────────────────────────────┐
│   浏览器访问管理后台                │
│   Browser → Admin Interface        │
│                                    │
│   URL: /core/group/{id}/           │
│        group_bottom_button         │
└────────────────────────────────────┘
   │
   ↓
Step 2: 配置按钮 (Configure Buttons)
   │
   ↓
┌────────────────────────────────────┐
│  点击"添加按钮"                     │
│  Click "Add Button"                │
│                                    │
│  • 按钮文本: "📋 群规"             │
│  • 按钮URL: https://...           │
│  • 显示顺序: 0                     │
│  • 启用: ✓                         │
└────────────────────────────────────┘
   │
   ↓
┌────────────────────────────────────┐
│  使用上移/下移调整顺序               │
│  Use Up/Down to adjust order       │
│                                    │
│  [↑] [↓] [编辑] [删除]             │
└────────────────────────────────────┘
   │
   ↓
Step 3: 推送到群组 (Push to Group)
   │
   ↓
┌────────────────────────────────────┐
│  点击"推送到群组"按钮                │
│  Click "Push to Group" button      │
│                                    │
│  ┌──────────────────────────┐     │
│  │ [推送到群组] 📤          │     │
│  └──────────────────────────┘     │
└────────────────────────────────────┘
   │
   ↓
┌────────────────────────────────────┐
│  确认对话框                         │
│  Confirmation Dialog               │
│                                    │
│  "确定要将当前按钮配置               │
│   推送到群组作为菜单键盘吗？"        │
│                                    │
│  [确定]  [取消]                    │
└────────────────────────────────────┘
   │
   ↓ [确定]
┌─────────────────────────────────────────────────────────────┐
│                      系统处理流程                            │
│                    (System Processing)                       │
└─────────────────────────────────────────────────────────────┘

Step 4: API 请求 (API Request)
   │
   ↓
┌────────────────────────────────────┐
│  JavaScript → Flask API            │
│                                    │
│  POST /core/api/                   │
│       push_group_bottom_buttons    │
│                                    │
│  Body: { group_id: 123 }           │
└────────────────────────────────────┘
   │
   ↓
Step 5: 后端处理 (Backend Processing)
   │
   ↓
┌────────────────────────────────────┐
│  1. 验证管理员权限                  │
│     Verify admin authentication    │
│                                    │
│  2. 查询数据库获取激活按钮          │
│     Query DB for active buttons    │
│                                    │
│  3. 构建 ReplyKeyboardMarkup       │
│     Build reply keyboard markup    │
│                                    │
│  4. 检查 Bot 是否就绪               │
│     Check if bot is ready          │
└────────────────────────────────────┘
   │
   ↓
Step 6: 异步发送消息 (Async Send Message)
   │
   ↓
┌────────────────────────────────────┐
│  asyncio.run_coroutine_threadsafe  │
│                                    │
│  await bot.send_message(           │
│    chat_id=group_chat_id,          │
│    text="📋 群组菜单已更新...",    │
│    reply_markup=keyboard           │
│  )                                 │
└────────────────────────────────────┘
   │
   ↓
┌─────────────────────────────────────────────────────────────┐
│                   Telegram Bot API                           │
│                                                              │
│  Bot → Telegram Servers → Group Chat                        │
└─────────────────────────────────────────────────────────────┘
   │
   ↓
┌─────────────────────────────────────────────────────────────┐
│                      群组显示效果                            │
│                    (Group Display)                           │
└─────────────────────────────────────────────────────────────┘

Step 7: 用户看到菜单键盘 (Users See Menu Keyboard)
   │
   ↓
┌────────────────────────────────────┐
│   Telegram 群组聊天界面             │
│   Telegram Group Chat Interface    │
│                                    │
│   [消息内容区域]                    │
│   [Message Area]                   │
│                                    │
│   ├─────────────────────┤          │
│   │ 📋 群组菜单已更新   │          │
│   │ 请点击下方按钮...   │          │
│   └─────────────────────┘          │
│                                    │
│   ┌─────────────────────┐          │
│   │  📋 群规            │ ← 按钮1  │
│   ├─────────────────────┤          │
│   │  👥 成员列表        │ ← 按钮2  │
│   ├─────────────────────┤          │
│   │  📊 积分查询        │ ← 按钮3  │
│   ├─────────────────────┤          │
│   │  💰 抽奖活动        │ ← 按钮4  │
│   └─────────────────────┘          │
│                                    │
│   持久化菜单键盘 (Persistent Menu) │
└────────────────────────────────────┘

┌─────────────────────────────────────────────────────────────┐
│                        功能特点                              │
│                       (Features)                             │
└─────────────────────────────────────────────────────────────┘

✅ 可视化配置 - 无需编写代码
✅ 一键推送 - 简单快捷
✅ 持久显示 - 始终可见
✅ 灵活排序 - 自由调整顺序
✅ 实时生效 - 立即推送到群组
✅ 安全可靠 - 权限验证 + 错误处理
