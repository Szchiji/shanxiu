配置备份与恢复

导出和导入群组配置

导出配置

导出当前群组/频道的可配置项为 JSON 文件。现已包含：

  • 群配置与资料字段（功能配置、其他设置中的开关和文案）
  • 自动回复、定时消息、/start 消息、群底部按钮
  • 积分规则、积分回复、积分商城/兑换、竞拍、成员等级
  • 关键词过滤、进退群、垃圾防护、强制订阅、不活跃用户、定时开关群、邀请活动
  • 同步规则、抽奖、投票、问答、插件开关
  • 频道转发规则、消息模板、频道帖按钮、优惠券配置

不会导出：认证用户名单、积分余额与流水、同步日志、邀请记录、警告和统计等运营数据，以及 Bot Token、小号 session、api_hash 等机密信息。

导出的文件可用于备份或迁移到其他群组
导入配置

从 JSON 文件导入配置。兼容旧版备份（只含自动回复、定时消息、积分规则、成员等级等字段的文件也可以导入，缺的部分会跳过，不会报错）。导入会更新已有的群配置，其他项目按名称补齐，不会清空未包含在文件里的数据。

点击选择文件或拖拽文件到此处

请谨慎操作，导入前建议先导出当前配置作为备份
